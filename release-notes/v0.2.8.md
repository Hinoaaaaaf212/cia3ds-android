# cia3ds-android v0.2.8

Large `.3ds` rebuild stability release.

* Fixes the app closing at the final rebuild step for large `.3ds` and `.cia` games. CIA and CCI output is now streamed from the decrypted partitions instead of loading multi-gigabyte content into memory.
* Decrypted cartridge images are streamed directly back into their original NCSD layout when possible.
* CIA-to-CCI/3DS output is built directly, avoiding an unnecessary multi-gigabyte intermediate CIA.

Same signing key as previous releases, so it installs straight over your existing copy.
