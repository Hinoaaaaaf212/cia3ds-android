# cia3ds-android v0.2.8

Large `.3ds` rebuild stability release.

* Fixes the app closing at the final rebuild step for large `.3ds` games. Decrypted cartridge partitions are now streamed directly back into the original NCSD layout instead of loading a multi-gigabyte image into memory and converting it through an intermediate CIA.
* Keeps memory use nearly constant during the final rebuild and avoids writing an unnecessary intermediate CIA.

Same signing key as previous releases, so it installs straight over your existing copy.
