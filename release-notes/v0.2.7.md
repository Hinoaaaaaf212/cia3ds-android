## cia3ds-android v0.2.7

Storage-safety release for large decrypts.

* Before native decrypt starts, cia3ds now checks cache and destination free space more conservatively for `.cia` and `.3ds` jobs. If there is not enough room, it stops early with a clear low-space message instead of starting work that may fail later.

Same signing key as previous releases, so it installs straight over your existing copy.
