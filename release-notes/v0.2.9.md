# cia3ds-android v0.2.9

CIA-to-CCI/3DS output fix.

* Fixes `.cia` to `.cci`/`.3ds` decrypts failing at the rebuild step with `makerom: [SETTING ERROR] '' could not be opened`. makerom's `-content <path>:<index>` argument parser mis-split single-colon paths (a long-standing upstream bug, Project_CTR #74/#152) and always produced an empty path; it now resolves the path/index split correctly for both `<path>:<index>` and `<path>:<index>:<id>` forms.

Same signing key as previous releases, so it installs straight over your existing copy.
